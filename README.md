# TechNova (តិចណូវ៉ា) 🚀

> **TechNova** គឺជាគេហទំព័រពាណិជ្ជកម្មអេឡិចត្រូនិច (E-Commerce Storefront) ទំនើបសម្រាប់លក់ឧបករណ៍បច្ចេកវិទ្យា កុំព្យូទ័រ និងគ្រឿងបន្ថែម (Tech Gadgets & Computer Accessories) ដែលត្រូវបានរចនាឡើងយ៉ាងស្រស់ស្អាត ងាយស្រួលប្រើប្រាស់ និងគាំទ្រភាសាខ្មែរយ៉ាងពេញលេញ។

## ✨ លក្ខណៈពិសេសចម្បង (Key Features)

- 🎨 **ការរចនាបែបទំនើប & ឆ្លើយតបគ្រប់អេក្រង់ (Modern & Responsive UI/UX):**
  - ប្លង់ស្រស់ស្អាត មើលទៅមានវិជ្ជាជីវៈ ដំណើរការរលូនទាំងលើទូរស័ព្ទ ថេប្លេត និងកុំព្យូទ័រ
  - មាន Hero Banner, Promotion Strips, និង Closing Sections ទាក់ទាញ
- 🇰🇭 **គាំទ្រភាសាខ្មែរ (Khmer Localization):**
  - ចំណុចប្រទាក់ជាភាសាខ្មែរ
  - បម្លែងកាលបរិច្ឆេទ និងលេខជាទម្រង់លេខខ្មែរ (ឧ. ០១២៣៤៥៦៧៨៩)
- 🔍 **ការស្វែងរក និងចម្រាញ់ផលិតផល (Live Search & Category Filtering):**
  - ស្វែងរកផលិតផលតាមឈ្មោះបានភ្លាមៗ (Instant Search)
  - ចម្រាញ់តាមប្រភេទផលិតផល (ទាំងអស់, កុំព្យូទ័រ, គ្រឿងបន្ថែម)
- 🛒 **ប្រព័ន្ធកន្ត្រកទំនិញ (Interactive Shopping Cart):**
  - បន្ថែមទំនិញទៅកាន់កន្ត្រក
  - បង្កើន/បន្ថយចំនួនទំនិញ និងលុបទំនិញ
  - គណនាតម្លៃសរុបដោយស្វ័យប្រវត្តិ
- 💳 **ទំព័របញ្ជាទិញទំនិញ (Checkout & Shipping Options):**
  - ទម្រង់បែបបទបំពេញព័ត៌មានអតិថិជន និងអាសយដ្ឋានដឹកជញ្ជូន
  - ការផ្ទៀងផ្ទាត់ទិន្នន័យត្រឹមត្រូវ (Form Validation)
  - ជម្រើសដឹកជញ្ជូនធម្មតា (ឥតគិតថ្លៃ) និងដឹកជញ្ជូនរហ័ស
- 🧾 **ទំព័រទទួលស្គាល់ការបញ្ជាទិញ (Order Confirmation):**
  - បង្ហាញលេខកូដបញ្ជាទិញ (Order ID)
  - សង្ខេបបញ្ជីមុខទំនិញ ព័ត៌មានអតិថិជន និងទឹកប្រាក់សរុប

## 🚀 របៀបដំឡើង និងដំណើរការ (Getting Started)

### លក្ខខណ្ឌតម្រូវ (Prerequisites)
- [Node.js](https://nodejs.org/) (Version 18+ ត្រូវបានណែនាំ)
- [npm](https://www.npmjs.com/) ឬ [pnpm](https://pnpm.io/)

### ការដំឡើង (Installation)

1. **ក្លូនគម្រោង (Clone Repository):**
   ```bash
   git clone https://github.com/gitrimsmos/Technova.git
   cd Technova
   ```

2. **ដំឡើង Dependencies (Install Packages):**
   ```bash
   npm install
   ```

3. **ដំណើរការក្នុង Dev Server (Start Development Server):**
   ```bash
   npm run dev
   ```
   បើកកម្មវិធីរុករក (Browser) ទៅកាន់: `http://localhost:5173`

4. **ការ Build សម្រាប់ Production (Build for Production):**
   ```bash
   npm run build
   ```

5. **ដំណើរការ Preview Build:**
   ```bash
   npm run preview
   ```
